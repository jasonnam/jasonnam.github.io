Porcelain

iOS 및 macOS를 위한 빠르고 깔끔한 네이티브 Git 클라이언트

iPhone • iPad • Mac 지원

주요 기능

풀 네이티브 Git 엔진

libgit2 기반으로 모바일 및 데스크톱 환경에서 빠르고 안정적인 오프라인 우선 버전 관리를 제공합니다.

통합 Diff 뷰어

나란히 배치된 라인 넘버 거터, 헝크 헤더 및 추가/삭제 구문 강조를 통해 코드 변경 사항을 손쉽게 검토합니다.

인터랙티브 스테이징 영역

원탭 제스처로 개별 파일을 스테이징/언스테이징하고 실시간 스테이징 개수를 확인하며 커밋합니다.

브랜치 관리 및 전환

로컬 및 원격 추적 브랜치를 생성하고 전환하며, 커밋되지 않은 변경 사항에 대한 안전 경고를 제공합니다.

원격 동기화 & 분기 탈출

HTTPS 또는 SSH로 Fetch, Pull, Push를 실행하며 Non-fast-forward 충돌 시 안전한 분기 탈출 옵션을 지원합니다.

기기 내 키체인 기반 보안

개인 액세스 토큰 및 SSH 키가 하드웨어 키체인에 안전하게 저장되며 기기 외부로 절대 유출되지 않습니다.

iOS 파일 앱 연동

외부 코드 편집기 및 텍스트 앱에서 저장소 작업 트리 파일에 직접 접근하여 편집할 수 있습니다.

유니버설 네이티브 경험

iPhone의 컴팩트 내비게이션, iPad의 3열 스플릿 뷰, macOS의 풀 데스크톱 메뉴를 완벽하게 지원합니다.

철저한 개인정보 보호

Porcelain은 표준 HTTPS 및 SSH 프로토콜을 통해 Git 서버와 직접 통신합니다. 제3자 서버, 분석 도구, 사용자 추적 및 데이터 수집이 전혀 없습니다.

자주 묻는 질문

Porcelain을 사용하려면 계정이 필요한가요?

계정이나 회원가입이 필요하지 않습니다. 오픈소스 저장소를 즉시 클론하거나 기존 토큰/SSH 키로 비공개 저장소에 연결할 수 있습니다.

SSH 키와 토큰은 어떻게 보호되나요?

모든 자격 증명은 Apple 키체인(kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly)을 통해 기기 하드웨어 내에서 안전하게 보호됩니다.

다른 텍스트 편집기에서 파일을 열 수 있나요?

네. iOS 파일 앱 및 파일 직접 열기를 완벽 지원하므로 다른 앱에서 저장소 내 파일을 직접 열고 편집할 수 있습니다.

오프라인 상태에서도 작동하나요?

네. Diff 확인, 스테이징, 커밋, 브랜치 관리, 커밋 로그 탐색 등 모든 로컬 Git 작업은 오프라인에서 동작합니다.

어떤 Git 호스팅 서비스를 지원하나요?

GitHub, GitLab, Bitbucket, Codeberg, Forgejo, Gitea 및 표준 HTTPS/SSH로 접근 가능한 모든 자체 구축 Git 서버를 지원합니다.
