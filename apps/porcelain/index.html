Porcelain

The clean, fast, and native Git client for iOS and macOS

Designed for iPhone, iPad & Mac

Key Features

Full Native Git Engine

Powered by libgit2 for robust, fast, and offline-first Git version control on mobile and desktop.

Unified Diff Viewer

Inspect code changes with side-by-side line number gutters, hunk headers, and syntax addition/deletion highlighting.

Interactive Staging Area

Stage and unstage individual files with one-tap gestures and track live staged change counts before committing.

Branch Management

Create, list, and switch between local and remote-tracking branches with safety checks for uncommitted changes.

Remote Sync & Escape Routes

Fetch, pull, and push smoothly over HTTPS or SSH, with built-in non-fast-forward divergence escape routes.

On-Device Keychain Security

Personal access tokens and SSH Ed25519/RSA keys are securely stored in your hardware Keychain and never leave your device.

iOS Files App Integration

Access and edit working tree files directly in third-party editors and IDEs via document-in-place integration.

Universal Experience

Tailored interfaces for compact iPhone navigation, 3-column iPad split views, and full macOS desktop menu integration.

Private by Design

Porcelain connects directly to your Git servers over standard HTTPS and SSH protocols. No third-party servers, no analytics, no tracking, and no data collection.

Frequently Asked Questions

Do I need an account to use Porcelain?

No account or registration is required. You can clone and manage public repositories immediately, or connect your private accounts using your existing tokens or SSH keys.

How are my SSH keys and tokens secured?

All credentials reside strictly inside Apple's Keychain Services with device-only hardware protection (kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly).

Can I edit files in other text editors?

Yes. Because Porcelain supports document-in-place and the iOS Files app, any editor that opens local files can work directly within your repositories.

Does Porcelain work offline?

Yes. All local Git operations—diffing, staging, committing, branch switching, and log browsing—run 100% offline.

Which Git hosting providers are supported?

Porcelain works with GitHub, GitLab, Bitbucket, Codeberg, Forgejo, Gitea, and any custom self-hosted Git server accessible over HTTPS or SSH.
